# GADM base geometry

The historical boundary layer in this folder was manually digitized in QGIS
from georeferenced historical map sheets, using the GADM 4.0 Indonesia level-0
shapefile as base geometry. The base dataset was downloaded on 30 March 2022.

No original GADM level-0 shapefile is bundled here. Download the base dataset
from the official archived [GADM 4.0 country download page](https://gadm.org/download_country40.html)
and select Indonesia if you need the original base geometry.
